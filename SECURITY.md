# Sicherheitsrichtlinie / Security Policy

## Unterstützte Versionen / Supported versions

Unterstützt werden der aktuelle Release und der Stand auf `main`.

The latest release and the current `main` branch are supported.

## Sicherheitslücken melden / Reporting vulnerabilities

Bitte melden Sie Sicherheitslücken ausschließlich über GitHubs **Private
Vulnerability Reporting** im Bereich **Security → Report a vulnerability**
dieses Repositorys. Veröffentlichen Sie keine Details in einem öffentlichen
Issue. Falls die private Meldefunktion nicht verfügbar ist, warten Sie bitte,
bis die Repository-Verantwortlichen einen vertraulichen Meldeweg bereitstellen.

Please report vulnerabilities only through GitHub **Private Vulnerability
Reporting** under **Security → Report a vulnerability** for this repository.
Do not disclose details in a public issue. If private reporting is unavailable,
please wait until the repository maintainers provide a confidential channel.

Beobachtete IP-Adressen, Journale, mutmaßliche Leak-Inhalte, Zugangsdaten und
andere personenbezogene oder sensible Daten gehören niemals in öffentliche
Issues, Pull Requests oder Diskussionen.

Never post observed IP addresses, journals, alleged leaked material,
credentials, or other personal or sensitive data in public issues, pull
requests, or discussions.

Es bestehen keine Garantien zu Reaktions- oder Behebungszeiten.

No response-time or remediation-time guarantees are provided.
